# 话题搜索视频评论采集设计

## Goal

在资讯模块的跨平台话题搜索中增加抖音、B站和快手的视频搜索，并在同一次话题搜索中自动采集这些视频的一级评论。评论随搜索结果临时展示，不进入资讯订阅、资讯库或搜索历史。

## Constraints

- 仅由跨平台话题搜索触发，不接入订阅刷新或全局采集任务。
- 搜索结果先返回，评论在后台异步采集，避免拉长当前有时限的搜索请求。
- 每个视频最多返回 10 条一级评论；抖音和 B 站最多扫描 100 条并按点赞数取前 10 条，快手维持当前页面可读结果；本期不抓二级评论。
- 按平台和视频分别报告状态；一个平台的限流、登录要求或失败不能阻断其他平台。
- 默认匿名访问。仅在用户显式启用并且该平台账号已连接时使用授权会话。
- 授权优先复用用户现有 Edge/Chrome 浏览器；凭据不得返回前端或写入日志。
- 评论和任务状态只保存在后端内存，并有清理期限；不新增数据库表或持久化评论。
- 尊重平台访问限制并使用有界并发与请求间隔，不尝试绕过验证码或访问控制。
- MediaCrawler 当前使用非商业学习许可证；只参考其“先搜索视频、再按视频拉评论”的流程，TabKeep 实现独立编写。

## Recommended Approach

1. 将抖音、B站、快手加入现有话题搜索 provider 合约和结果选择器。每个平台适配器负责关键词搜索、视频 ID/标题/链接/作者/时间字段归一化和分页；抖音和 B 站评论适配器最多扫描 100 条并按点赞数降序返回前 10 条。
2. 搜索接口为每次搜索创建短期内存评论任务，并立即返回视频结果和任务标识。任务只处理该次搜索新出现的视频，按平台限流并对单视频设置评论数量上限。
3. 新增受现有新闻访问 Token 保护的评论任务状态查询接口。任务结果按视频 key 返回评论、进度和平台错误状态；过期任务自动清理。
4. 话题搜索界面轮询该任务并在视频卡片中显示评论数量、采集状态和可展开的评论列表。关闭页面不持久化任务或评论。
5. 将三个平台加入现有授权设置。授权时连接当前 Edge/Chrome 并在其新标签中打开平台登录页；用户自行完成登录或平台验证。授权仍默认不用于搜索，只有用户开启对应授权搜索选项后才使用已连接会话。
6. 所有请求及解析按平台隔离。遇到登录要求、验证码、HTTP 限制、超时或解析变化时，保留已取得的视频结果，显示可读状态，并停止该来源后续评论请求。

## Alternatives Considered

- **同步采集后返回**：实现路径较短，但搜索请求需要等待多个视频的评论翻页，容易超过现有平台请求时限；不采用。
- **用户逐条点击视频后采集**：请求量最可控，但增加了逐视频操作，也不符合搜索时自动收集评论的目标；不采用。
- **搜索后后台自动采集**：先返回视频结果，再独立展示评论进度；保持搜索交互响应，并让评论任务只在话题搜索期间启动；采用。

## File/Component Impact

- `backend/schemas/news.py`：扩展平台、视频结果、评论任务和评论响应模型。
- `backend/routers/news.py`：扩展话题搜索并增加任务状态查询接口。
- `backend/services/news/topic_search.py`：将三个视频平台加入搜索编排与授权状态。
- `backend/services/news/`：实现隔离的视频搜索/评论适配器与短期内存任务管理。
- `backend/services/storage.py`、`backend/services/news/topic_search_auth.py`：扩展账号偏好和现有浏览器授权流程。
- `desktop/news-reader/src/api.ts`、`TopicSearchPanel.tsx`、`styles.css`：扩展 provider 合约、任务轮询、状态和评论展示。

## Risks

- 三个平台使用的网页接口、分页游标、签名参数和登录要求可能变化；适配器必须将失败限制在单个平台，并提供明确诊断状态。
- 浏览器远程调试连接受 Edge/Chrome 的用户确认、浏览器休眠标签和并发页面状态影响；连接失败时显示原因，不自动启动额外浏览器或访问本机以外的调试端点。
- 评论内容及账号昵称属于用户数据；评论不落库、不写入诊断日志，展示只保留实现功能所需字段。
- 任务为内存态，后端重启后不可恢复；接口需要报告任务不存在或已过期。
- 平台条款和 MediaCrawler 的许可证约束独立适用；不复制其源代码，未来用途变化时需重新核对许可及平台条款。

## Validation Plan

- 检查新增平台 ID 在后端 schema、搜索编排、授权状态、前端 API 类型和 UI 选项间一致。
- 检查搜索响应不等待评论任务；评论任务状态按平台和视频正确隔离，超时或限流不会覆盖已返回的视频结果。
- 检查任务过期清理、默认匿名偏好、凭据不进入日志/响应、评论不写入资讯数据库。
- 不新增或运行自动化测试；实现完成后是否执行构建或手动验证由用户另行提出。
