# 漫画区域检测评估集

该目录用于离线比较漫画区域检测方案，不参与正式应用运行。

## 数据结构

- `manifest.json`：评估用例及人工标注。
- `images/`：测试截图。仅放允许本地评估使用的图片，不提交私人或受版权限制的原图。
- `predictions/`：脚本生成的检测结果。

每个用例至少标注气泡级 `textBounds`。有气泡边界时同时标注 `bubbleBounds`；OCR 和翻译评估可以继续补充 `sourceText`、`expectedTranslation`。

## 建议构成

| 场景 | 建议数量 |
| --- | ---: |
| 日漫横排 | 10 |
| 日漫竖排 | 10 |
| 英文漫画 | 8 |
| 彩色 Webtoon | 8 |
| 无气泡或复杂背景文字 | 4 |

区域检测以 `IoU >= 0.5` 视为命中，主要查看 Precision、Recall 和 F1。模型替换前后必须使用同一份标注集。
