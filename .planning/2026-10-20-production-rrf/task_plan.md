# 正式资讯推荐切换到 RRF

## 目标

将正式推荐接口的主排序切换为 RRF，融合关键词与语义榜单；向量缓存复用现有本地 embedding 缓存，embedding 未启用或请求失败时回退到关键词排序。最新列表保持不变，不打包安装版。

## 阶段

1. [x] 审查评估 embedding/cache、API 路由、前端状态与测试边界
2. [x] 提取或复用语义评分与本地缓存，使正式推荐可生成语义榜
3. [x] 正式推荐默认用 RRF，失败时关键词回退并给出状态
4. [x] 增加缓存、RRF、回退相关的后端回归测试
5. [x] 运行后端测试、前端构建和差异检查；不运行真实 provider、不生成安装包

## 决策约束

- RRF 常数沿用 60，RRF 公式与开发评估一致。
- embedding 只使用用户已配置的服务；无配置或服务失败不阻塞资讯页，回退关键词。
- 不在本轮后台预热或批量发送整库文章；只在用户打开“推荐”视图时计算未缓存所需向量，单次请求限制新向量批量，后续由缓存复用。
- 明确标示关键词回退状态；最新列表不调用 embedding。
- 保留其他工作区改动；不打包、不提交。
