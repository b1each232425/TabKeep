## 已确定决策

| 决策 | 原因 |
|---|---|
| 最新列表继续按时间排序 | 推荐改进不应改变时间线语义 |
| 人工标注 30 篇 | 作为个人本机初步评估，不宣称统计结论 |
| 评估标签不写入兴趣事件 | 防止标签进入训练画像造成评估泄漏 |
| 只在显式运行时调用配置的 embedding API | 尊重用户数据边界 |
| 不引入 K-means，不增加正式画像 UI | 保持多兴趣、先验证效果 |
| 不重新打包 | 当前目标是后端基线和排序验证 |
| 语义服务不可用时终止本次评估 | 生产推荐始终只走关键词排序；失败不会写评估报告或改变推荐结果 |
| 测试页只存在于 Vite 开发环境 | 用户要求正式下载版本不带该交互页；开发 API 也通过启动器显式打开 |
