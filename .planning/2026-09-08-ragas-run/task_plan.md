# TabKeep 完整 Ragas 评估运行计划

## 目标

使用当前正式的 56 条评估集，在现有知识库索引和模型配置下完成一次完整的检索、答案生成及 Ragas 评估，并保存可复查的运行数据。

## 阶段

- [completed] 检查评估集、索引、配置和本地服务状态
- [in_progress] 运行 56 条完整评估并等待结束
- [pending] 保存汇总与逐用例结果，校验记录完整性
- [pending] 汇报指标、失败数、缓存状态和记录位置

## 运行约束

- 不输出或写入 API Key。
- 保留当前用户代码和数据，不重建索引、不修改评估集。
- 评估请求使用当前评估台配置；Ragas 仅在存在预期答案且答案生成成功的用例上运行。
- 如果服务未启动，只启动必要的本地开发服务，不执行安装包构建。

## 错误记录

| 错误 | 尝试 | 处理 |
| --- | --- | --- |
| 本地 38471 和 5175 返回 502 | 初次状态检查 | 继续检查端口/进程，必要时只启动评估所需服务 |
| 开发启动器退出后子进程未保留 | 使用 `pnpm dev:backend` 后端未监听 | 改用同一运行器内启动后端、调用评估并在结束时回收 |
| 直接导入 Ragas 超过 30 秒 | 单独导入探测超时 | 评估时允许 Ragas 冷启动，使用 5 分钟单用例 Ragas 超时 |

## 运行参数

- 检索模式：`hybrid`
- 检索 TopK：`10`
- 答案评估：`56` 条
- Ragas：所有符合条件的用例，五项指标，单条超时 `180` 秒
- 结果文件：`backend/evaluation/rag/runs/<runId>.json`
