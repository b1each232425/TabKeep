# TabKeep 项目复盘更新计划

## 目标

基于当前 TabKeep 工作树和已有 `杂项/TabKeep项目复盘` 文档，产出一版比旧复盘更详细、按主题组织、与当前代码一致的项目复盘材料。保留已准确的历史背景，标清已实现、实验/评估、待改进内容。

## 阶段

- [completed] 盘点当前架构、未提交变更、已有复盘目录结构与内容
- [completed] 梳理后端、扩展、桌面端、RAG/知识库、新闻阅读与推荐、工程发布的实现证据
- [completed] 更新复盘文档和索引，补充实现链路、取舍、缺陷、改进与面试追问
- [completed] 按需求逐项核对文档与当前代码，检查链接、遗漏和事实准确性

## 约束

- 不回滚、不覆盖代码工作树中已有的用户改动；本任务只编辑复盘文档及本计划目录。
- 代码现状优先于旧复盘、README 和规划文档。
- 区分已交付功能、实验/评估能力、计划中能力和明确缺陷。
- 不运行测试；本任务是代码阅读与文档整理，用户没有要求测试。

## 错误记录

| 错误 | 处理 |
| --- | --- |
| 初次 `rg` 同时检索了不存在的 `cst/backend` 路径 | 忽略该路径，后续只检索真实 `TabKeep/` 仓库 |
| PowerShell 不支持 `rg` 路径参数中的 Bash 花括号展开 | 改为显式列出源码文件路径 |

## 本轮工具错误补充

- 一次查询命令传入 PowerShell 通配路径导致未按预期展开，改为显式列出文件或直接查询目录。
- 首轮写文档的 JavaScript 模板字符串被 Markdown 围栏符号提前结束；该次未执行写入，改用波浪号围栏并显式调用 PowerShell 7 后完成。
- 首轮目录检查未反映最新文件状态，使用显式 PowerShell 7 重新检查完整清单和内容。
- 一次修订脚本把 PowerShell 反引号换行符放进 JavaScript 模板字符串导致解析失败；该次未执行写入，改用 Environment.NewLine 后成功更新。
