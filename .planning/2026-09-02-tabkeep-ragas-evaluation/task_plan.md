# TabKeep Ragas 评估引入调查与实施计划

## 目标

基于 TabKeep 当前 RAG 检索、问答和评估台实现，判断 Ragas 接入的完成度，找出缺口，并产出分阶段、可验证的实施计划。本轮只调查和规划，不修改业务代码。

## 阶段

- [completed] 盘点现有 RAG 链路、评估模型、依赖和测试
- [completed] 核对 Ragas 当前官方能力与 TabKeep 版本适配边界
- [completed] 设计数据集、指标、运行方式、成本和结果持久化
- [completed] 形成 MVP / 后续增强路线和验收标准

## 约束

- 保持本地优先和开发期评估定位，Ragas 不进入生产后端包。
- 优先复用现有评估用例、知识库检索链路和评估台。
- 先区分检索评估与端到端答案评估，避免把 Ragas 分数和现有规则评估混为一谈。
