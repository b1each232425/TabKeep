# TabKeep 专属 RAG 评估集构建计划

## 目标

从用户自己的 TabKeep 笔记中提取有依据、可追溯的问题与标准答案，构建可供现有 RAG 评估台导入和运行的评估集。

## 阶段

- [completed] 定位并读取截图对应的本地笔记数据
- [completed] 设计字段、去重规则和数据集划分
- [completed] 生成问题、标准答案、参考文档/段落和元数据
- [completed] 校验格式、来源可追溯性和现有评估链路兼容性

## 约束

- 只使用用户自己的笔记作为知识来源，不混入网络通用问答。
- 标准答案必须能在笔记中找到依据；无法确认的内容标记为待人工审核，不直接进入正式集。
- 保留原笔记标题、路径/文档 ID 和段落信息，便于 Context Recall 与检索结果回溯。
- 先生成可审阅、可版本管理的 JSON 中间数据，再写入 SQLite 评估用例表。
- 本次使用 14 个去重后的笔记主题，每个主题 2 条用例：1 条基础理解题、1 条机制/优化题，共 28 条。
- 目标数据库为仓库内 `backend/data/knowledge.db`，不修改已安装版本的数据目录。
